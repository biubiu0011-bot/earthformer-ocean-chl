# 海表变量影响机制分析工具使用指南

## 概述

这套工具用于分析不同海表变量（叶绿素、海表温度、盐度、海面高度、海流等）对叶绿素浓度预测的影响机制。

## 文件结构

```
├── main_analysis.py          # 主分析脚本（完整版）
├── quick_analysis.py         # 快速分析脚本（简化版）
├── attention_analysis.py     # 注意力机制分析
├── gradient_attribution.py  # 梯度归因分析
├── sensitivity_analysis.py  # 敏感性分析
├── run_analysis.sh          # 便捷运行脚本
├── README_analysis.md       # 详细说明文档
└── usage_guide.md           # This guide
```

## 分析方法说明

### 1. 敏感性分析
- **目的**: 评估每个海表变量对预测结果的影响程度
- **方法**: 
  - 扰动分析：给变量添加噪声，观察性能变化
  - 消融研究：移除变量，观察性能下降
- **输出**: 变量重要性排序

### 2. 梯度归因分析
- **目的**: 分析输入变量对预测结果的直接贡献
- **方法**: 使用积分梯度计算归因值
- **输出**: 每个变量的贡献度分布

### 3. 注意力机制分析
- **目的**: 分析模型内部的注意力权重
- **方法**: 提取注意力层的权重分布
- **输出**: 注意力热力图和权重分析

## 结果解读

### 重要性等级
- **高重要性** (>5% 性能变化): 关键变量，必须重点关注
- **中重要性** (1-5% 性能变化): 重要变量，有显著影响
- **低重要性** (<1% 性能变化): 次要变量，影响较小

### 典型结果示例
```
变量重要性排序:
1. chla: +8.5% (重要性: 高)    # 叶绿素本身最重要
2. sst: +3.2% (重要性: 中)     # 海表温度影响较大
3. ssh: +1.8% (重要性: 中)     # 海面高度有一定影响
4. sss: +0.8% (重要性: 低)     # 盐度影响较小
5. ssu: +0.3% (重要性: 低)     # 海流u分量影响很小
6. ssv: +0.2% (重要性: 低)     # 海流v分量影响最小
```

## 常见问题

### Q1: 运行时出现CUDA内存不足
```bash
# 解决方案：使用CPU或减少batch_size
python main_analysis.py --device cpu
```

### Q2: 模型加载失败
```bash
# 检查文件路径
ls -la experiments/train_34/checkpoints/

# 使用快速测试验证工具
python quick_analysis.py --use_dummy_data
```

### Q3: 注意力分析失败
这是正常的，某些模型可能不包含显式的注意力层。工具会自动跳过这部分分析。

### Q4: 结果不合理
- 检查数据预处理是否正确
- 确认模型是否收敛
- 验证配置文件是否匹配

## 实际应用建议

### 1. 数据收集策略
- 优先保证高重要性变量的数据质量
- 在资源有限时，可以降低低重要性变量的采样频率

### 2. 模型改进方向
- 为高重要性变量设计专门的特征提取模块
- 考虑变量间的交互作用

### 3. 预测策略优化
- 在某些变量缺失时，重点补全高重要性变量
- 根据变量重要性调整预测权重
