# Results and model weights

> English version. [Original README](README.md)

Predictions, TensorBoard events, logs, checkpoints, and large arrays are intentionally ignored by Git. Set `EARTHFORMER_OCEAN_CHL_RESULTS_ROOT` to a local output directory before a run.

If verified weights are released later, distribute them through GitHub Releases or another archival service together with the exact configuration, checkpoint hash, and a compact metrics table. Do not commit large run outputs to this repository.
