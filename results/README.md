# Results and model weights

> English version: this document is maintained in English.

Generated predictions, TensorBoard events, logs, checkpoints, and large arrays are intentionally ignored by Git.

Set `EARTHFORMER_OCEAN_CHL_RESULTS_ROOT` to the directory where your run outputs should be written. A future release should attach a verified checkpoint and a small result table through GitHub Releases or another archival service, together with the exact config and checkpoint hash used to compute reported metrics.
