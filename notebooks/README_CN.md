# Notebooks

> English version: this document is maintained in English.

The historical Argo notebooks are retained locally as reference material but are intentionally ignored by Git. Their code cells still contain research-workspace paths and have not yet been converted into portable, reviewed scripts.

Public, reproducible implementations should be added to `scripts/` or `analysis/`. After a notebook has been converted, reviewed, and stripped of machine-specific paths, it may be added back deliberately.

The current replacements are `merge_bgc_argo_profiles.py`, `process_bgc_argo_profiles.py`, `match_argo_to_nemo.py`, `extract_argo_metadata.py`, `build_argo_transfer_samples.py`, and the `analysis/` Argo comparison/plot scripts.
