# Notebooks

> English version. [Original README](README.md)

Historical Argo notebooks are retained locally as reference material but ignored by Git because their code cells still contain research-workspace paths. Public replacements live in `scripts/` and `analysis/`: profile merge/processing, NEMO matching, metadata extraction, validated transfer-sample writing, comparison, and figures.

Do not publish a notebook until it has been reviewed, made portable, and stripped of machine-specific paths.
